## 二、建议补(排期 1.1)

- 离线地图缓存(骑行山区无信号)
- 车辆保养提醒(按里程/时间)
- 多车辆快速切换(首页下拉)
- 推送通知细分开关(同路/徽章/活动/系统)
- 骑行数据周/月统计视图
- 路线天气/路况提示(出发前)
- 打卡点到达前主动提醒
- 同路骑士在线状态 + 实时距离展示
- 隐私协议/用户协议入口从设置页常驻

## 三、流程优化建议

1. 开始骑行前增加「路线天气/路况」卡片,降低新手风险
2. 打卡点接近时主动通知(已在通知开关预留,待接后台位置触发)
3. 同路骑士列表显示在线状态与距离(ride_presence 表已建,待 UI 展示)
4. 「选择目的地」按钮在无骑行状态时提示改为「先选择出发路线」,避免歧义
5. 首页车辆卡增加 chevron 进入编辑的视觉反馈(需设计确认,不擅自加)

## 四、已在本轮落地(第 12 节)

- 骑士主页(资料/座驾/打招呼)
- 路线聊天(群聊消息流)
- 路线收藏(星标 + 筛选)
- 同路骑士列表行可点 → 骑士主页
