# App Store 上架文案(可直接复制到 App Store Connect)

> 2026-08-17 | 与 `docs/APPSTORE-CHECKLIST.md` 配套使用,本文件是可复制的最终文案。

## 1. 名称与副标题

- **名称**:WELL WAY(≤30 字符,OK)
- **副标题**:摩友路线·打卡·同路人

## 2. 关键词(逗号分隔,≤100 字符)

`摩托车,骑行,路线,打卡,摩友,同路,轨迹,徽章,活动,车辆`

## 3. 描述(审核展示用,≤4000 字符)

```
WELL WAY 是摩托车骑行社区:精选骑行路线、沿途打卡、点亮徽章,
还能遇到同路摩友,一起出发。

• 路线:按城市/难度/里程筛选,卡片与列表两种模式,一键收藏
• 打卡:沿路线打卡点签到,记录里程与时长,生成专属骑行总结
• 徽章:每完成一次骑行点亮一枚徽章,收集你的骑行成就
• 同路人:同路线/同目的地的摩友即时提醒,路线聊天室交流
• 我的P房:管理你的车辆与常用目的地,出发前快速选择
• 活动:报名线下骑行活动,查看剩余名额与详情

匿名即可使用全部功能;绑定邮箱可换设备恢复数据。
位置仅在骑行时记录,用于生成轨迹,结束后不再获取。
```

## 4. 审核备注(App Review Notes)

```
1. 登录:邮箱验证码走开发测试模式,任意 6 位数字均可通过(如 123456)。
2. 测试账号:可匿名使用,无需注册。
3. 位置权限:首次开始骑行时请求;骑行中持续获取用于生成轨迹,
   结束后停止获取。审核时可用模拟器定位或"虚拟位置"。
4. 所有页面无需登录即可浏览;收藏/打卡/聊天等需要数据的功能
   在匿名状态下自动创建本地账号。
```

## 5. 隐私政策 URL

- 先托管 `docs/PRIVACY-POLICY.md` 内容(建议 GitHub Pages 或自有域名),把网址填入 App Store Connect「隐私政策」栏。
- 联系邮箱占位符:`<请在提交前填写您的联系邮箱>` 需替换为真实邮箱。

## 6. 支持网址(可选)

- 可将隐私政策同一页面或 GitHub 仓库页作为支持网址。
