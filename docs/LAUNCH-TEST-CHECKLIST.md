# WELL WAY 上线测试清单(2026-08-22)

> 目标:上架 App Store 前把「核心闭环 + 权限 + 异常场景 + 机型适配」全测一遍。
> 标注 🔴 的必须真机;其余模拟器可测。每项按「步骤 → 预期」执行,完成后打勾。

## 0. 测试环境准备

- [ ] 跑迁移:`backend/supabase/migrations/ALL.sql` 全量执行一次(含 0010 路线图、0011 操作日志),后台刷新后确认「路线 → 编辑」出现「路线图」上传框,顶栏出现「操作日志」Tab
- [ ] 后台给 2 条线上路线各传一张路线图(SVG 或透明底 PNG),App 端确认显示
- [ ] 真机:开发者模式信任证书、装上 Debug 包、首次启动允许通知
- [ ] 准备两个测试账号(邮箱 A/B),用于同路/聊天测试
- [ ] 准备弱网环境(飞行模式 / 网络限制工具)

## 1. 账号与登录(🔴 真机)

- [ ] 首次启动:开屏动画完整播放、不卡顿、品牌图标居中
- [ ] 「创建新账户」→ 邮箱验证码(测试模式任意 6 位)→ 进首页
- [ ] 登录后杀掉 App 重开:会话保持,不重复登录
- [ ] 「随便看看」游客模式可用;游客进入需要账号的功能(骑行/收藏/报名)有明确提示
- [ ] 退出登录 → 数据不残留(回到登录页)
- [ ] 错误场景:错误验证码、空邮箱、无网络登录,均有中文友好报错

## 2. 车型库 / 首页(模拟器)

- [ ] 首页空状态:「选择更多路线」按钮点击后跳到热力轨迹 Tab
- [ ] 右上角「+」添加车辆 → 品牌 → 车型 → 填写昵称/颜色 → 保存
- [ ] 有车状态:首页展示品牌车型、里程数据框;点卡片可编辑
- [ ] 编辑车辆后重启 App,数据仍在

## 3. 路线浏览与详情(模拟器)

- [ ] 路线列表卡片模式:左右滑动切换路线、分页点跟随
- [ ] 卡片上滑收纳:跟手 → 松手飞行 → 停在灵动岛下方 → 点击/下拉展开,无白屏、无漂移
- [ ] 列表模式:搜索、省份/城市/难度/里程筛选、收藏筛选
- [ ] 路线详情:标题返回位置正确;路线图(后台上传图)显示;里程/时长/打卡点/难度一致
- [ ] 收藏路线 → 详情页星标状态同步 → 收藏筛选可见

## 4. 骑行闭环(🔴 真机,核心)

- [ ] 开始骑行前:定位权限弹窗出现且文案正确(首次真机必弹;模拟器不弹)
- [ ] 骑行中:地图轨迹实时绘制、速度/里程/时长递增;锁屏/切后台后继续记录(后台定位)
- [ ] 骑行中打卡:接近打卡点半径内自动/手动打卡,打卡点列表状态变化
- [ ] 结束骑行:总结页出现(里程/时长/均速/爬升/打卡明细);可重命名、可删除
- [ ] 轨迹落库:后台 SQL `select * from ride_records order by started_at desc limit 5;` 有记录;`ride_points` 有点
- [ ] 徽章:该路线全部打卡 → 自动发放徽章(`badges` + `user_badges` 落库),个人中心可见
- [ ] 弱网骑行:中途断网不闪退,恢复网络后数据正常保存

## 5. 活动报名(模拟器)

- [ ] 活动列表/详情展示:名额、时间、奖励正确
- [ ] 报名成功 → 名额 -1 → 详情页显示已报人数;重复报名有提示
- [ ] 后台「活动」表格可看到报名记录;`activity_registrations` 表数据正确

## 6. 同路骑士 / 聊天 / 提醒(🔴 真机,两台设备)

- [ ] A/B 同时在同一条路线骑行 → 「队伍/同路骑士」列表互相出现,距离字段合理
- [ ] A 在路线聊天发消息 → B 3 秒内收到;聊天记录持久化
- [ ] 通知开关:设置页「同路提示/打卡完成/骑行完成」分别开关生效
- [ ] 骑行中收到同路提醒:不弹全屏/横幅遮挡,只提示音或轻提醒,不影响驾驶(见 `docs/COMPANION-ALERT-DESIGN.md`)

## 7. 个人中心 / 设置(模拟器)

- [ ] 个人资料展示(昵称/头像/车辆);头像可换
- [ ] 骑行记录列表:历史总结可进入、可删除
- [ ] 徽章墙:已获得徽章展示、未获得置灰
- [ ] 关于与反馈:提交反馈成功提示;隐私政策/用户协议入口可打开
- [ ] 通知权限被拒后:设置页对应开关置灰/引导去系统设置

## 8. 异常与边界(模拟器 + 🔴 真机)

- [ ] 无网启动:不白屏,给出「网络不可用」+ 重试
- [ ] 弱网(飞行模式关掉 Wi-Fi 开蜂窝):列表加载有 loading,失败可重试
- [ ] 极慢网络:登录/列表/详情均不无限转圈,有超时提示
- [ ] 空数据:未添加车辆/无路线/无徽章等空状态文案正确
- [ ] 大字号(系统字体放大):主要页面不破版、文字不截断(至少首页/详情/列表)
- [ ] 前后台切换、来电打断:骑行记录不丢、界面恢复正常

## 9. 机型适配(模拟器)

- [ ] iPhone 17(已测)/ iPhone 16 Pro Max(6.9″)/ iPhone SE(小屏 4.7″):首页、路线详情、骑行页无越界/重叠
- [ ] 灵动岛机型:卡片收纳停靠不重叠灵动岛
- [ ] 深色模式:主要页面可读(当前为黑白主题,确认无黑底黑字)

## 10. 管理后台验收(浏览器)

- [ ] 登录 → 各 Tab(品牌/车型/路线/打卡点/徽章/活动)增删改查正常
- [ ] 路线图上传:SVG 自动转 PNG;透明底 PNG 上传后 App 端背景透明(不是黑/白底)
- [ ] 操作日志:后台做一次新增+修改+删除 → 「操作日志」Tab 出现对应 3 条记录(操作人/时间/变更摘要)
- [ ] 后台数据与 App 端实时一致(改名称后 App 重进即变)

### 模拟器快速回归命令(供重复测试)

```bash
cd ios && xcodebuild -project WELLWAY.xcodeproj -scheme WELLWAY \
  -destination 'platform=iOS Simulator,name=iPhone 17' -derivedDataPath build build
xcrun simctl install booted build/Build/Products/Debug-iphonesimulator/WELLWAY.app
xcrun simctl launch booted com.wellway.WELLWAY
```
